# Парсер товаров и категорий

Проект предоставляет инструменты для работы с товарами и категориями:

## Основные возможности

1. **Классы данных**:
   - `Product` - товар с названием, описанием, ценой и количеством
   - `Category` - категория товаров с названием, описанием и списком товаров

2. **Функционал**:
   - Загрузка данных из JSON-файла
   - Автоматический подсчет товаров и категорий
   - Создание объектов товаров и категорий

3. **Тестирование**:
   - Проверка загрузки данных
   - Тестирование обработки ошибок
   - Проверка счетчиков

## Использование

1. Создайте JSON-файл с данными о категориях и товарах
2. Используйте функцию `load_data_from_json()` для загрузки
3. Работайте с полученными объектами Category и Product

## Пример структуры JSON

```json
[
  {
    "name": "Категория",
    "description": "Описание",
    "products": [
      {
        "name": "Товар",
        "description": "Описание",
        "price": 1000,
        "quantity": 5
      }
    ]
  }
]
```
## Запуск тестов

```bash
pytest tests
```
