# Парсер товаров и категорий

Проект предоставляет инструменты для работы с товарами и категориями:

## Основные возможности

1. **Классы данных**:
   - `Product` - товар с:
     - Приватным атрибутом цены с валидацией
     - Подтверждением при понижении цены
     - Автоматическим объединением дубликатов
   - `Category` - категория с:
     - Приватным списком товаров
     - Строгой типизацией добавляемых товаров
     - Автоматическим подсчетом продуктов

2. **Функционал**:
   - Загрузка данных из JSON-файла (`load_data_from_json()`)
   - Геттеры для безопасного доступа к данным
   - Валидация данных при создании и изменении
   - Автоматическое обновление счетчиков:
     - `Product.total_products`
     - `Category.category_count`
     - `Category.product_count`

3. **Тестирование**:
   - 100% покрытие основных сценариев
   - Проверка:
     - Инкапсуляции атрибутов
     - Валидации входных данных
     - Работы с пользовательским вводом
     - Обработки ошибок

4. **Строковые представления**
   - `Product`: "Название, цена руб. Остаток: X шт."  
     Пример: `"Телефон, 50000 руб. Остаток: 3 шт."`
  
   - `Category`: "Название категории, количество продуктов: X шт."  
     Пример: `"Электроника, количество продуктов: 5 шт."`  
     (Суммирует quantity всех товаров категории)

5. **Математические операции**
- Сложение товаров (`product1 + product2`) возвращает суммарную стоимость всех единиц:  
  `(цена1 × кол-во1) + (цена2 × кол-во2)`

## Новые возможности

### Классы-наследники
- `Smartphone` (наследует `Product`):
  - Доп. атрибуты: производительность, модель, память, цвет
- `LawnGrass` (наследует `Product`):
  - Доп. атрибуты: страна, срок прорастания, цвет

### Ограничения операций
1. **Сложение**:
   - Только товары одного класса
   - `TypeError` при попытке сложить разные типы
   - Пример: `smartphone1 + smartphone2` (работает), `smartphone + lawn_grass` (ошибка)

2. **Добавление в категорию**:
   - Только объекты `Product` и его наследники
   - `TypeError` при попытке добавить другой тип

## Примеры использования

```python
# Строковое представление
print(product)  # "Ноутбук, 120000 руб. Остаток: 2 шт."
print(category) # "Техника, количество продуктов: 7 шт."

# Сложение товаров
total_value = product1 + product2  # Суммарная стоимость на складе
```
## Использование

1. Создайте JSON-файл с данными о категориях и товарах
2. Используйте функцию loader_data для загрузки
    ```python
    from src.loader import loader_data
    
    categories = loader_data('products.json')
    ```
3.  Работайте с полученными объектами Category и Product
```python
from src.commerce import Product, Category
# Создание товара
new_product = Product.new_product({
    'name': 'Новый товар',
    'description': 'Описание',
    'price': 1500,
    'quantity': 10
})

categories = Category(
        "Смартфоны",
        "Смартфоны, как средство не только коммуникации, но и получения дополнительных функций для удобства жизни"
    )

# Добавление в категорию
categories.add_product(new_product)
```
