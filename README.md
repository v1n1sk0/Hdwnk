# Продукты, категории и заказы

Проект представляет собой систему управления продуктами, категориями и заказами с базовой функциональностью.

## Основные возможности

### Классы данных

1. **`Product`** - базовый класс продукта:
   - Атрибуты: название, описание, цена, количество
   - Автоматическое обновление общего количества продуктов
   - Строковое представление: "Название, цена. В наличии: X шт."

2. **`Category`** - класс категории:
   - Атрибуты: название, описание, список продуктов
   - Автоматический подсчет продуктов в категории
   - Строковое представление: "Название категории, количество продуктов: X шт."

### Дополнительная функциональность

- Загрузка данных из JSON (`load_data_from_json()`)
- Валидация данных при создании объектов
- Логирование операций с помощью `LoggingMixin`
- Специальные методы для работы с продуктами:
  - `Product.total_products` - общее количество продуктов
  - `Category.category_count` - количество категорий
  - `Category.product_count` - количество продуктов в категории

### Особые операции

- **Сложение продуктов**:  
  `product1 + product2` создает новый продукт с суммарной стоимостью:  
  `(цена1 × количество1) + (цена2 × количество2)`

## Базовые классы

### `BaseProduct`
- Абстрактный базовый класс для всех продуктов
- Реализует основные методы: `__init__`, `__str__`
- Запрещает прямое создание экземпляров

### `BaseContainer`
- Базовый класс для контейнеров (категорий и заказов)
- Обеспечивает базовую функциональность для работы с коллекциями

## Класс Order

Реализует функциональность заказов:
- Содержит информацию о продукте
- Количество товара в заказе
- Общая стоимость заказа
- Наследуется от `BaseContainer`

### Обработка нулевого количества
- При создании товара с `quantity=0` вызывается `ValueError`
- Пользовательское исключение `ZeroQuantityError` для случаев:
  - Добавления товара с нулевым количеством в категорию
  - Создания заказа с нулевым количеством
- Полный цикл обработки с сообщениями:
  - Успешное добавление
  - Ошибка добавления
  - Финализация обработки (блок `finally`)

### Средняя цена категории
- Метод `average_price()` в классе `Category`
- Автоматическая обработка случая пустой категории
- Возвращает 0 если нет товаров

## Примеры использования

```python
# Создание смартфона с логированием
phone = Smartphone("iPhone", "Флагман", 100000, 5, 
                  "A15", "13 Pro", "128GB", "Black")

# Создание заказа
order = Order("Мой заказ", "Доставка", phone, 2)
print(order)  # Заказ 'Мой заказ': iPhone - 2 шт. На сумму 200000 руб.
```
